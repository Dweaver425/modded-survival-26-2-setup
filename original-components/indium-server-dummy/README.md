# Indium Server Dummy

**Author:** Dylan Weaver (Minecraft username: Stixity)

This is the one pack-original mod component in the Modded Survival 26.2 distribution. It is a metadata-only Fabric dedicated-server compatibility shim used by Dylan's combined Voxy Server and Distant Horizons deployment.

The JAR contains no executable classes or third-party code. Its only payload is the included [`fabric.mod.json`](fabric.mod.json), which declares a server-only provider for the `indium` mod ID so the dedicated server does not need the client rendering mod.
